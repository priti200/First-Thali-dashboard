# Swasth-Thali POC v7

This version is deliberately self-contained and robust:
- The initial Phase 1 dashboard is written directly into index.html.
- CSS is embedded directly into index.html.
- JavaScript is embedded directly into index.html.
- All 51 image assets are local.
- Clicking a school opens the Phase 2 portion/nutrition page.
- The School selector also opens the school page.

Open `index.html` after extracting the ZIP. No npm, backend, API, or build step is required.

All values/images are mock prototype content.
